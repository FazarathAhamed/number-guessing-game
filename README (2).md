# 🔢 Number Guessing Game

A fun terminal-based number guessing game built with Python.

## 🎮 Features

- 3 difficulty levels: **Easy**, **Medium**, **Hard**
- Random number generation using Python's `random` module
- Win / Lose logic with attempt tracking
- Input validation and range checking
- Play again option 



> Requires Python 3.x — no extra libraries needed!

## 🕹️ How to Play

1. Choose a difficulty level
2. Guess the secret number within the allowed attempts
3. The game tells you if your guess is too high or too low
4. Win by guessing the correct number before running out of chances!

## 📊 Difficulty Levels  

| Level  | Range  | Attempts |
|--------|--------|----------|
| Easy   | 1–50   | 10       |
| Medium | 1–100  | 7        |
| Hard   | 1–200  | 5        |

## 🛠️ Built With

- Python 3
- `random` module (built-in)
